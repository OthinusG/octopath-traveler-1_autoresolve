功能说明

只对地图行走触发的普通随机暗雷生效。达到等级门槛后，Mod 跳过战斗转场，结算敌群基础奖励。Boss、剧情战、固定事件战、比试与唆使都保留正常战斗；无法确认的遭遇也不会自动结算。

EXP经验与职业点数

结算 EXP、JP 和金钱，并应用静态队伍被动与 EXP/JP 饰品加成。

DROP概率掉落

按原生背包容量加入掉落物；满堆叠时只截断道具数量。

F6快捷开关

按 F6 切换并保存启用状态，提示语言跟随游戏界面语言。

不模拟破防、无伤等战斗表现奖励、偷窃、捕获、首次怪物发现或后期稀有猫替换。

结算条件

仅当最高上场等级达到敌群与地区等级门槛时，才会跳过普通暗雷战斗：

最高上场等级 ≥ max（地区危险等级，抽中敌群最高等级）+ LevelMargin

默认 LevelMargin=1。即使等级符合，非普通随机遭遇仍进入原生战斗。

  • 倒下角色不获得 EXP、JP 或升级回复；存活的满级角色仍可获得 JP。
  • 角色真正升级后，该角色恢复 HP/MP；没有升级的角色不会被治疗。
  • 获得的金钱会调用游戏原生累计金钱记录接口。

安装

适配 Windows Steam build 5272616。Mod-only ZIP 不含加载器，请先安装官方 UE4SS 3.0.1。

  1. 退出游戏并打开游戏目录：Octopath_Traveler\Binaries\Win64。
  2. 解压下载的 ZIP，将其中的 Win64/Mods/OT1AutoResolve 文件夹复制到： 
    Octopath_Traveler\Binaries\Win64\Mods\
  3. 在现有 Mods\mods.txt 中增加一行，保留其他条目： 
    OT1AutoResolve : 1
  4. 进入地图后 Mod 即可生效。按 F6 可以关闭自动结算。

上面的路径对应发布页提供的 Mod-only ZIP。若使用源码归档，Mod 文件夹位于 mod/OT1AutoResolve，不是安装包内部路径。

设置

配置文件位于 Mods\OT1AutoResolve\config.ini。编辑后重启游戏。

[AutoResolve]
Enabled=1
ToggleKey=F6
LevelMargin=1
ShowUI=1
Enabled
1 启用，0 关闭；快捷键会保存此值。
ToggleKey
支持 F1–F24；设为 None 可禁用快捷键。
LevelMargin
等级差范围 0–99，默认 1；设为 0 可同等级结算。
ShowUI
1 显示奖励提示，0 隐藏。

升级与卸载

升级

只替换 OT1AutoResolve\Scripts 文件夹，保留已有 config.ini 和其他 Mod。

卸载

退出游戏，删除 Mods\OT1AutoResolve 文件夹，并移除 Mods\mods.txt 中对应的一行。其他 Mod 仍需 UE4SS 时，请保留共享加载器文件。

常见问题

按 F6 没有反应怎么办？

检查 Mods/mods.txt 是否包含 OT1AutoResolve : 1，并确认 config.ini 中的 ToggleKey 不是 None。手动编辑配置后需重启游戏。

为什么普通敌人仍进入战斗？

检查队伍等级是否达到当前门槛，并确认该战斗由地图移动触发。Boss、剧情、固定事件、比试、唆使及无法确认的遭遇始终保留正常战斗。

奖励异常时去哪里查看记录？

Mod 不主动保存游戏。接口不可用时会保留正常战斗；奖励写入异常会停止后续自动结算，记录在游戏的 Win64/UE4SS.log 中。
