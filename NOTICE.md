# Notices

The port's reference implementations were OT2AutoResolve and FFRS AutoResolve v1.0.1. Their archives and binaries are not part of this source distribution.

`catalog.lua` contains the numerical encounter/reward catalogue required by the mod, generated from the target OT1 game build. Raw game assets, textures, text tables, Blueprint exports, SDK dumps and save files are excluded. This project is an unofficial mod and has no affiliation with the game's publisher.

UE4SS is an external runtime, distributed separately under its upstream terms. No UE4SS binary is included here.

The optional development table reader referenced by `tools/build_catalog.py` originates from MarvinXLII/OctopathTravelerJobRandomizer and requires local compatibility adjustments described in the development notes. Third-party reader source is not bundled.
